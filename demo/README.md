# Test fixtures

These files are inputs for the automated suite. The fictional Alex Morgan resume documents exercise DOCX and PDF parsing; the text file supplies known rubric and profile data. The example phone is from the 555-0100–0199 fictional-use range, and the email uses example.com.

The handwriting images are synthetic geometry cases. They cover one or three lines, low contrast, blur, a disconnected page edge, rotation and blank input. They test line segmentation and preprocessing, and should not be used to estimate handwriting recognition accuracy.
